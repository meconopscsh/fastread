# 6秒リーディング

6秒の黙読で読めた字数を測り、目のストレッチと「読めないくらいの速さで目で追う」練習をはさんで、もう一度測る個人用の練習ツールです。
手順は、週刊女性PRIMEの記事（2017年）で紹介された呉真由美さんの速読トレーニングを参考にしています（公式のものではありません）。

## 使い方

`index.html` をブラウザで開くだけで動きます（ダブルクリックでも可）。

確認用のサーバーで開く場合は次のとおりです。

```
node tools/serve.mjs
```

→ http://localhost:8787/

記録はブラウザの localStorage に保存されます。保存先は開き方ごとに分かれ、`file://` で開いたときと `http://localhost:8787` で開いたときの記録は別々になります。どちらか一方の開き方に決めて使ってください。
ときどき「記録」画面から JSON で書き出しておくと安心です。

## スマホ（Android）で使う

ホーム画面に入れて使えるWebアプリ（PWA）になっています。GitHub Pages で公開しています。

→ https://meconopscsh.github.io/fastread/

1. スマホの Chrome で上のURLを開き、メニューの「ホーム画面に追加」（または「アプリをインストール」）を選びます。
2. `main` に push すると、1〜2分で公開中の版も新しくなります。
3. ホーム画面のアイコンから開くと、全画面で動きます。一度開いたあとは、ネットにつながっていなくても使えます。

- ネットにつながっているときは、開くたびに新しい版を読み込みます。
- 指で使えるように、読めた最後の文字はタップで選び、◀ ▶ で1字ずつ直せます。キー操作の案内は出ません。
- セッションの間は画面が消えないようにしています。「戻る」を押すと、中断するかを聞きます。
- トレーニングでは、⚑が画面に収まるように文字を小さくします（狭い画面では10pxまで）。目で追うだけなので、読めなくて構いません。
- 計測で、画面に出ていた最後の字まで読めたときは、案内が出ます。設定で文字を小さくすると、もっと先まで測れます。
- 記録はスマホの中に保存され、パソコンの記録とは別になります。移したいときは JSON の書き出し・読み込みを使ってください。画面の大きさが違うので、パソコンとスマホの字数はそのまま比べないほうが安全です。
- `file://` で開いたときは、PWA の機能（インストール・オフライン）は使えません。

## 1回の流れ

1. 事前計測：読み始めの位置に3・2・1の数字が出て（ピッ・ピッ・ピッ、0.4秒ごと）、ポーンで6秒だけ本文を表示します。6秒の終わりにも音が鳴ります。音量は「設定」で変えられます。消えたら、読めた最後の文字をクリックします（←→で1字ずつ調整、1/2/3で内容の分かり具合、Enterで確定）。
2. 目のストレッチ：左右・上下・遠近・視野の4種目を、各12回行います。拍ごとに高い音と低い音が交互に鳴り、種目の終わりにも音が鳴ります。
3. トレーニング：事前計測の字数×3の位置に⚑を立て、読めないくらいの速さで6秒×3回、目で追います。
4. 再計測：続きの、まだ読んでいない文章で6秒測ります。

比較用の回では、ストレッチとトレーニングの代わりに、休憩とふつうの読み直しをします。休憩の時間が終わると音が鳴ります。

## 文章を増やす

`tools/build-texts.mjs` の `WORKS` に、青空文庫の作家IDと作品名（新字新仮名版）を足してから、次を実行します。

```
node tools/build-texts.mjs [キャッシュ用フォルダ]
```

これで `texts.js` が作り直されます。外字（画像の字）が出てきたときは、スクリプトの `GAIJI` に対応する字を足してください。

## ファイル

- `index.html` … アプリ本体（HTML・CSS・JavaScript）
- `texts.js` … 収録作品の本文（自動生成、青空文庫）
- `tools/build-texts.mjs` … 青空文庫から本文を取得・整形するスクリプト
- `tools/serve.mjs` … 確認用の静的サーバー（依存なし）
- `manifest.webmanifest` … PWA の設定（アプリ名、アイコン、縦向きなど）
- `sw.js` … オフラインでも開けるように、ファイルを保存しておく Service Worker
- `icons/` … アプリのアイコン
